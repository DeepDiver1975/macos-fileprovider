* *2026-08-16 (on a Mac)*: Added `OwnCloudCore.RemoteClient` — the transport seam every Phase 4 operation builds on — test-first (127 tests green). It turns a `RemoteRequest` into an HTTP round-trip via `URLRequestFactory`, attaches `Authorization`, and translates the response: 2xx → body bytes, any other status → the classified `RemoteError` thrown; a transport-level failure propagates unchanged. The network call is an injected `async` performer, so request-shaping + response-classification are tested with a stub (no live server) and the type stays Linux-buildable; a `URLSession`-backed `.urlSession(_:)` performer is provided for production. 5 tests (success body, auth header, 404→noSuchItem, 412→versionConflict, transport-error passthrough). This gives the replicated-extension handlers a single tested chokepoint for issuing the Phase 4 `RemoteRequest`s and mapping failures; the remaining Mac-only glue is byte streaming to/from the FileProvider temp-URL hand-off.
